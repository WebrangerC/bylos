While listening to [[LyT 15 Karen Hume Deep Dive]] I was inspired to really try to freewrite AND use the freewriting as personal source notes. Karen's discussion of using the Calendar dots as a way to see connected with me so I wanted to put freewrite space in my Daily Note, but allow it to become a part of a Higher Order Note (workbench). This is what I decided on:
1. FreeWrite in my Daily Note and start the piece with a line containing a freewrite tag and title. 
2. When done with the initial effort, refactor the freewrite selection to a new note with the title and body. (this leaves a tag in my Daily Note to the new note so I have a freewrite tag and a link).
3. Clean up the new note making the title a header and adding an "Expand" header below the initial writing.
4. In my daily note, transclude the title section after my freewrite tag. This leaves a breadcrumb on the day I wrote and a tag to find my freewriting.
